# AI Customer Feedback & Dispute Annotator 🤖📊

A practical Python tool designed to automate text classification, sentiment detection, and case routing for back-office and customer operations teams.

## 🌟 Features
- **Auto-Categorization:** Identifies transaction disputes, technical issues, and general inquiries.
- **Priority Assessment:** Assigns routing priority (High, Medium, Low).
- **Data Annotation Pipeline:** Formats output into JSON for model fine-tuning and operational metrics.

## 🚀 How to Run
```bash
python app.py
